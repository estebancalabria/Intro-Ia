# Azure

* Es una platafora de Microsoft que tiene un monton de servicios entre ellos muchos que me permiten programar herramientas de IA delegandole a estos servicios la parte dificil
* Para implementar soluciones de IA para ciertos casos de uso de alto impacto:
    * Conocer qeu servicios de IA tenemos disponibles para programar (o contratar a alguien que lo programe) para implmenentar estos casos uso

* URL
  * https://portal.azure.com/
 
* Microsoft Foundry
  * Agrupador de todos los servicios de IA de Azure
    * Modelos Pre Entrenados
    * Microsoft Foundry
      * https://ai.azure.com/
      * Permite utilizar modelos mediante API Key
    * SpeechService
      * Text-To-Speech y Speech-To-Text
      * Reconoce el idioma
      * Podriamos programar una app como taqtic o naturalreaders
      * https://speech.microsoft.com/
    * Language Service
      * Sirve para classificar y enteder texto de una manera rapida y economica sin necesidad de llegar a usar un LLM
      * Discriminar resenias positivas/negativas de un foro de intenet
      * https://language.cognitive.azure.com/home
    * Translator
      * Para traducir texto de un idioma otro
      * Mucho mas economico que usar un llm
    * Content Safety
      * Para tener un moderador automatico
    * Computer Vision / Face Api
      * Son Modelos pre entrenado para reconocer objetos, contaro objetos, reconocer personas
      * https://portal.vision.cognitive.azure.com/
    * Health Insights
      * Modelos pre entrenados con Datos de Salud
    * Bot Service
      * Te permite programar chatbots mas deterministicos
    * Document Intelligence
      * Permite procesar imagenes (pueden ser muchas) en lote y a partir de ahi generarme un texto estructurado con la informacion
    * Ai Serarch
      * Permite generar bases de datos de mucho texto y hacer busqeudas semanticas
  * Entrenar tu propio modelo
     * Custom Vision
       * Entrenar tus propios modelos de IA para reconocer imagenes
       * https://www.customvision.ai/
     * Machine Learning
       * https://ml.azure.com/
       * Permite entrenar modelos de ML con muchos mas datos que SimpleMl for sheets
