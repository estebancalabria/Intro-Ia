# Copilot

* No es un modelo de lenguaje en si. Es una pasarela con filtros estrictos que te permtie usar los modelos de OpenAI o Claude
  * Tiene filtros de uso responsable de la IA

## Diferencias entre Copilot Chat y Copilot 365

* Las mil caras de Copilot
  * Copilto Chat
      * https://copilot.microsoft.com/
      * Lo puede usar cuaqluiera con su cuenta personal de microsoft sin licencia
      * Es como un chatgpt de microsoft para el usuario domestico
      * No tiene privacidad, nada nos asegura Microsoft de que se hace con la conversaciones
          * No se les ocurra ni aca, ni en chatgpt ni en ningun llm domestico poner informacion sensible o privada
  * Copilot para 365
      * https://m365.cloud.microsoft/
      * Ya requiere la licencia
      * Esta pensado para uso organizacional / para empresas
      * Tiene proteccion de datos de empresa
          * Tengo mas libertad para usar datos sensibles o privados sin que salgan del entorno de la organizacion ni se usen para entrenar modelos
            
## Copilot 365

* Caratesticas
  * Proteccion de datos empresariales
  * Integracion con ecosistema 365
    * OneDrive
    * Outlook
    * Calendar
    * Office
      * Powerpoint
      * Word
      * Excel
    * Sharepoint
  * Filtros estrictos de Etica
  * Seleccion del modelo
 
### Integracion con 365

* Outlook (MAIL)
  * "Dame un resumen de los correos que recibi la ultima semana"
* Calendar
  * "Creame hoy de 16:00 a 17:00 una reunion con el cliente Grupo Provincia"
* OneDrive
  * "Listame los ultimos archivos con los que trabaje en one drive esta ultima semana"
  * Recomendacion : Utilizar mas OneDrive y no tener todo almacenado en la computadora local
  * Grounding : 365 automaticamente busca grounding en los archivos de sharepoint y onedrive para dar respuestas basadas en ellos
  * Lo puedo no solo usar sino alimentar como fuente de conocimiento de mi trabajo

#### Memoria

* (Arriba ala derecha) -> (...) Elipsis -> Configuracion -> Personalizacion -> Recuerdos Guardados -> "Administrar Memorias Guardadas"
* "Haceme con tu memoria un pelfil de empleado de mi usuario"
* Puedo pedirle a copilot que recuerde explicitamete algo "Recorda que me gusta el helado de frutilla" y va a la memoria
* Podemos eliminar de la memoria datos que no nos parecen relevantes
